# 요괴야행 (Yokai Night March)

한국 신화 테마 뱀파이어 서바이버즈 스타일 로그라이크 서바이벌 게임. 10분을 살아남아라.

## 실행

```bash
# 브라우저에서 직접 열기
open index.html

# 또는 로컬 서버
python3 -m http.server 4173
# → http://localhost:4173
```

## 조작

- **데스크톱**: WASD / 방향키로 이동, 무기 자동 공격
- **모바일**: 화면 왼쪽 절반 터치 조이스틱
- **일시정지**: ESC / P

## 게임 시스템

**무기 5종** (자동 공격, 레벨업으로 강화)
- ⚔️ 퇴마검 — 플레이어 주위를 회전
- 🔥 부적불꽃 — 가장 가까운 적에게 발사
- ⚡ 번개부 — 랜덤 적에게 낙뢰
- ❄️ 빙결파동 — 주변 적 감속
- 🌫️ 저주안개 — 독안개 지속 피해
- 🔮 혼령장 — 접촉 적에게 지속 피해

**진화 무기 3종** (기본 무기 조합으로 진화)
- 👻 귀신참 = 퇴마검 + 혼령장
- 👹 귀화염 = 부적불꽃 + 저주안개
- 🌩️ 뇌빙 = 번개부 + 빙결파동

**패시브 7종**: 최대HP, 이동속도, 자석, 방어력, 쿨타임감소, 경험치보너스, 재생력

**적 6종**: 도깨비, 쥐불, 해골병사, 처녀귀신, 여우분신, 구미호(보스)

## 기술 스택

- HTML5 Canvas + Vanilla JS
- Web Audio API (사운드 이펙트)
- 외부 의존성 없음

## 배포

- **Steam**: Electron으로 래핑
- **모바일**: Capacitor 또는 PWA
- **웹**: 정적 호스팅 (Vercel, Netlify 등)
