# 요괴야행 (Yokai Night March) v3.0

한국 신화 테마 뱀파이어 서바이버즈 스타일 로그라이크 서바이벌 게임. 10분을 살아남아라.

## 실행

```bash
# 브라우저에서 직접 열기
open index.html

# 또는 로컬 서버
python3 -m http.server 4173
# → http://localhost:4173
```

## 조작

- **데스크톱**: WASD / 방향키로 이동, 무기 자동 공격
- **모바일**: 화면 왼쪽 절반 터치 조이스틱
- **일시정지**: ESC / P

## v2.0 주요 기능

### 캐릭터 시스템 (6종)

| 캐릭터 | 시작 무기 | 특성 | 해금 조건 |
|---------|-----------|------|-----------|
| 🗡️ 퇴마사 | 퇴마검 | 균형잡힌 기본 캐릭터 | 기본 |
| 🏮 무녀 | 부적불꽃 | 경험치 +30%, 쿨타임 -5% | 기본 |
| ☯️ 도사 | 빙결파동 | HP 150, 방어력 +3 | 누적 500처치 |
| 🏹 사냥꾼 | 번개부 | 속도 +25%, 공격력 +15% | 10분 클리어 |
| 📿 승려 | 혼령장 | 공격력 +20%, HP 120 | 무기 진화 달성 |
| 🦊 반요 | 저주안개 | HP 낮을수록 공격력 증가 | 구미호 처치 |

### 메타 진행 (영구 강화)

게임 중 골드를 획득하여 영구 능력치를 강화합니다:
- 체력/공격력/이동속도/방어력/자석/쿨타임/경험치/재생력/골드보너스
- 부활 (사망 시 HP 30%로 1회 부활)
- 최대 10레벨까지 강화 가능

### 난이도 시스템

| 난이도 | 적 체력 | 적 공격력 | 골드 보상 | 해금 조건 |
|--------|---------|-----------|-----------|-----------|
| 🟢 쉬움 | x0.7 | x0.7 | x0.5 | 기본 |
| 🟡 보통 | x1.0 | x1.0 | x1.0 | 기본 |
| 🔴 어려움 | x1.5 | x1.3 | x1.5 | 기본 |
| 💀 악몽 | x2.5 | x1.8 | x2.5 | 10분 클리어 |

## 무기 시스템

### 기본 무기 (8종)

| 무기 | 설명 |
|------|------|
| ⚔️ 퇴마검 | 플레이어 주위를 회전하는 퇴마검 |
| 🔥 부적불꽃 | 가장 가까운 적에게 부적 불꽃 발사 |
| ⚡ 번개부 | 랜덤 적에게 번개 낙뢰 |
| ❄️ 빙결파동 | 주변 적을 얼려 느리게 만듦 |
| 🌫️ 저주안개 | 독안개를 퍼뜨려 지속 피해 |
| 🔮 혼령장 | 접촉한 적에게 지속 피해 |
| 📿 염주 | 넓은 궤도로 도는 기도 구슬 |
| 🌪️ 풍백 | 주변 적을 밀어내며 피해 |

### 진화 무기 (4종)

| 진화 무기 | 조합 | 효과 |
|-----------|------|------|
| 👻 귀신참 | 퇴마검 + 혼령장 | 광범위 회전 + 처치 시 HP 회복 |
| 👹 귀화염 | 부적불꽃 + 저주안개 | 추적 화염 + 연쇄 폭발 |
| 🌩️ 뇌빙 | 번개부 + 빙결파동 | 번개 동결 + 폭발 파편 |
| 🌟 신풍염주 | 염주 + 풍백 | 바람 구슬 궤도 + 넉백 + 지속피해 |

진화 조건: 두 기본 무기 모두 Lv 5 이상

## 적 시스템

### 일반 적 (6종)

| 적 | 패턴 |
|----|------|
| 도깨비 | 추적 + 돌진 |
| 쥐불 | 빠른 군체 이동 |
| 해골병사 | 원거리 공격 |
| 처녀귀신 | 은신 + 텔레포트 |
| 불가사리 | 느린 탱커 (골드 다량 드롭) |

### 엘리트/보스

| 적 | 등장 시기 | 특징 |
|----|-----------|------|
| 🐉 이무기 | 45초마다 | 사행 이동, 3방향 투사체, 보물상자 드롭 |
| 🦊 구미호 | 5분 경과 | 분신 소환, 매혹, 최종 보스 |

### 보물상자 시스템

- 엘리트/보스 처치 시 보물상자 드롭
- 엘리트 상자: 골드 보너스 / 즉시 레벨업 / 완전 회복 (랜덤)
- 보스 상자: 대량 골드 + HP 50% 회복 + 모든 보석 흡수

## 기술 스택

- 순수 JavaScript + HTML5 Canvas
- 외부 라이브러리/에셋 0개 (제로 의존성)
- Web Audio API 절차적 BGM + 효과음
- PWA 지원 (Service Worker + 오프라인)
- localStorage 영구 저장 (골드, 강화, 기록, 해금)
- 공간 해싱 기반 충돌 최적화
